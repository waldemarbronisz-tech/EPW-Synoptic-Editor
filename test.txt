# 4. ELECTRICAL CONNECTIONS

Add dedicated connection objects:

```text
AC Wire
3-Phase Line
DC Wire
Control Wire
PE Connection
N Connection
Busbar
Cable
```

Connections must not behave like normal equipment blocks.

They should behave as line/network objects.

They must support:

* connection points,
* snapping,
* active/inactive preview,
* future runtime state binding.
